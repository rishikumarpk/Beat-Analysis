① Time Domain — Raw Waveform

The raw audio signal: amplitude x[n] plotted against time. This is what Fourier analysis starts with.

STEP 1
Upload a WAV file to see the waveform
1
What you see: The speaker membrane displacement over time. Peaks = loud moments, zero crossings = silence transitions.
2
Problem: Looking at the waveform tells us nothing about pitch, harmony, or beat frequency. We need to decompose it into frequencies — that's what the FFT does.

② FFT — Magnitude Spectrum

How much of each frequency is present in the entire song.

STEP 2
// Discrete Fourier Transform
X[k] = Σn=0N-1 x[n] · e−i2πkn/N
// Magnitude = |X[k]| = √(Re² + Im²)
// Frequency = k · sr / N (Hz)

③ Phase Spectrum

The angle φ[k] of each complex FFT bin — how offset each frequency component is.

STEP 3
X[k] = |X[k]| · eiφ[k]
φ[k] = arctan( Im{X[k]} / Re{X[k]} )
// Range: −π to +π radians
Awaiting analysis
🔵 Phase is usually random-looking for music — but phase differences between consecutive STFT frames are used to detect onsets and transients precisely.

④ STFT Spectrogram — Frequency × Time

Short-Time Fourier Transform: slide a Hann window across time, compute FFT for each frame. Result = frequency content evolving over time.

STEP 4
STFT(x)[m,k] = Σn x[n] · w[n−mH] · e−i2πkn/N
// w = Hann window, H = hop size (512), N = frame size (2048)
// Each column = one FFT. Horizontal = time. Vertical = frequency.
Awaiting analysis
A
Bright horizontal streaks = sustained tones (like a veena drone or sustained vocal note).
B
Bright vertical flashes = transients (mridangam hits, kick drums, claps) — these are the beat moments.
C
Window size tradeoff: larger window → better frequency resolution, worse time resolution. We use 2048 samples (≈46ms at 44.1kHz).

⑤ Onset Envelope + Beat Peaks

Bass-band energy change per frame. Peaks = where you tap your foot.

STEP 5
// 1. Band-pass 60–250 Hz (Butterworth filter)
E[m] = RMS(bass_frame[m])
onset[m] = max( E[m] − E[m−1], 0 )
// 2. Peaks above threshold = beats
threshold = mean + 0.5 × std

⑥ Autocorrelation — Tempo Curve

Finds the most likely BPM by measuring self-similarity at different delays.

STEP 6
R[τ] = Σn onset[n] · onset[n+τ]
// Computed via FFT: O(N log N)
BPM(τ) = 60 · sr / (τ · hop)
// Peak of R → dominant tempo
